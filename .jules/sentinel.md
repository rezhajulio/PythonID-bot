## 2026-09-22 - Secure Error Messages\n**Vulnerability:** Telegram bot replied with raw exception details in error messages (e.g. `f"❌ Terjadi kesalahan: {e}"`).\n**Learning:** This exposes internal state or dependencies to arbitrary users on Telegram.\n**Prevention:** Never include unhandled exceptions in user-facing bot responses. Instead, log them internally with `logger.error(..., exc_info=True)` and return a generic error text.
